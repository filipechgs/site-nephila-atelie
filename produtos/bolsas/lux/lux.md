# Lux

Lux é a unidade de medida que indica a iluminância, ou seja, a quantidade de luz que atinge e ilumina efetivamente uma superfície. A Bolsa Lux é aquele acessório para mulheres que gostam de brilhar o suficiente para ser destaque, mas sem causar ofuscamento. Uma bolsa clássica, mas única. Uma junção das duas técnicas, crochê e macramê, para aproveitar o melhor de cada uma.

- Fio poliéster com lurex 5mm, forro tricoline, metal de alta qualidade.

Técnica: Crochê e macramê
